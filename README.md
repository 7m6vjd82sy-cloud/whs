# WHS ギフトコード一括入力

最大100人分のプレイヤーIDに、ギフトコードをまとめて入力するサイトです。

## 公開方法（GitHub Pages・無料）

1. GitHub で新しいリポジトリを作る（例：`whs`、Public）
2. `index.html` をアップロードする（「Add file」→「Upload files」）
3. リポジトリの「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存する
4. 数分後に `https://<ユーザー名>.github.io/whs/` で開けるようになる

## 使い方

- プレイヤーIDを1行に1人入れる。`ID:メモ` の形でメモ（州番号など）も付けられる
- 「共有リンクをコピー」で、ID一覧入りのリンクを作れる（`#players=ID:メモ,...` の形式。参考サイトと同じ）
- ギフトコードを入れて「一括入力を開始」
- 画像認証を求められた場合は、画面に出る画像の文字を入力する

## うまく動かないとき

### 「公式APIに接続できませんでした」と出る

ブラウザが別サイトへの通信を止めている（CORS）可能性があります。中継サーバーを作ってください。

1. https://dash.cloudflare.com で無料アカウントを作る
2. 「Workers & Pages」→「Create」→「Create Worker」
3. `worker.js` の中身を貼り付けて「Deploy」
4. 表示されたURL（例：`https://xxx.workers.dev`）を、サイトの「詳細設定」→「APIのURL」に入れる

### 「混雑中」が多い

「詳細設定」の待ち時間を 2000〜3000 ミリ秒に増やしてください。
